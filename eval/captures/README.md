# Captures de test

Placez ici vos 10 captures d'écran de graphiques (PNG ou JPEG), puis
renseignez les valeurs réelles dans `../verite_terrain.yaml`.

Conseil : variez les cas — image nette, image floue, graphique sans
échelle de prix, timeframe absent — pour mesurer si le modèle répond
bien `null` quand il ne peut pas lire, au lieu d'inventer.

Ces images ne sont pas commitées par défaut si elles contiennent des
informations de compte : vérifiez avant de `git add`.
