Studio ZIP

Ouvrez une archive, renommez-la et renommez son contenu, regardez les images qu'elle contient, puis créez un nouveau fichier .zip.

1. Le fichier de départ

Déposez un fichier .zip ici ou cliquez pour le choisir — vous pouvez aussi déposer directement des images pour fabriquer une archive à partir de rien

2. Le nom de la nouvelle archive

Tapez le nom que vous voulez, ou utilisez un des boutons pour le générer. L'extension .zip est ajoutée toute seule.

3. Le contenu

Les # deviennent un numéro (photo-### → photo-001). L'extension d'origine est conservée. Vous pouvez aussi cliquer un nom dans la liste pour le corriger à la main.
